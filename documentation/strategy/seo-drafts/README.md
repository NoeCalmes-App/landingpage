# Brouillons SEO (à relire)

Les brouillons d'articles générés par la tâche programmée hebdo atterrissent ici.

- 1 brouillon par semaine, sur le prochain sujet `pending` de `../seo-content-plan.md`.
- Rien n'est publié automatiquement. Tu relis, tu ajustes, tu intègres (voir « Comment intégrer un brouillon » dans le plan).
- Chaque fichier : `NN-slug.md` avec, en haut, les métadonnées prêtes à coller dans `BLOG_ARTICLES` (`src/Blog.jsx`), puis le contenu HTML de l'article.
