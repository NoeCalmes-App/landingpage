# Landing Page — Noe Calmes

Site public `noecalmes.fr` pour convertir du trafic Instagram / LinkedIn / SEO vers un audit gratuit, WhatsApp ou un appel Calendly.

## Commandes

```bash
npm install
npm run dev
npm run build
```

`npm run build` lance Vite puis `scripts/generate-routes.js` pour generer les routes SEO statiques dans `dist`.

Tous les assets publics sont sous `public/assets`.

Ne pas recreer d'anciens dossiers comme `img`, `src/assets/app`, `src/assets/lib` ou `src/assets/font`.
